# Problem Solving

This section is for short Python exercises that build coding speed and fluency.

## Goal
- practice writing code without heavy setup
- improve comfort with control flow and data handling
- turn Python basics into coding muscle

## Layout
- `01-basic-challenges/`: values, types, arithmetic, simple conversions
- `02-control-flow-and-functions/`: conditions, loops, functions
- `03-collections-and-strings/`: lists, dictionaries, tuples, strings

## Suggested Format
- one problem per notebook or markdown file
- include the prompt, solution, and a short explanation
- keep each solution small and focused
