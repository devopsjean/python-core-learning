# Python Core Learning

A study repository for Python fundamentals, problem solving, and small practical projects.

## Overview
This repo is organized around three tracks:

- `10-core-concepts/`: language basics, notes, and runnable notebooks
- `20-problem-solving/`: short coding exercises for building coding fluency
- `30-mini-projects/`: practical Python scripts connected to automation and SRE-style tasks

## Structure
- `10-core-concepts/01-09`: one topic per folder
- `20-problem-solving/`: categorized challenge space
- `30-mini-projects/`: project-based practice
- `Makefile`, `requirements.txt`: local notebook environment setup

## Format
- `notes.md`: short concept summaries and review points
- `examples.ipynb`: runnable notebook examples with saved output
- `practice.ipynb`: short exercises and line-by-line analysis when needed

## Current Focus
The repo is designed to support this flow:

1. Learn one Python concept
2. Solve a few short problems
3. Build a small practical script
