# Core Concepts

This section holds the language-first part of the repo.

## Goal
Build a solid understanding of Python syntax, values, control flow, functions, data structures, and modules.

## Structure
- each topic lives in its own numbered folder
- `notes.md`: concept summary and review points
- `examples.ipynb`: runnable concept experiments
- `practice.ipynb`: optional short exercises for the topic
