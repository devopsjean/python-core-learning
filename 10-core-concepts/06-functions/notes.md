# Functions

## Core idea
A function is a reusable block of code that can accept input and return output.

## What to check
- `def`
- Parameters and arguments
- `return`

## Common confusion
- `print()` and `return` are not the same
- A function runs only when it is called

## Study focus
- Function definition
- Positional arguments
- Return values
