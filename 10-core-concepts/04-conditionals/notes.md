# Conditionals

## Core idea
Conditionals let a program choose different paths based on a condition.

## What to check
- `if`, `elif`, and `else`
- Comparison operators
- Logical operators like `and`, `or`, and `not`

## Common confusion
- `==` checks equality
- `=` assigns a value

## Study focus
- Boolean expressions
- Branching logic
- Comparison rules
