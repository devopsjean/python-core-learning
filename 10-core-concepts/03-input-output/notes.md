# Input and Output

## Core idea
Input brings data into a program, and output shows results to the user.

## What to check
- Basic `print()` usage
- String formatting with f-strings
- `input()` always returns text

## Common confusion
- `input()` returns `str`
- `print()` displays a value but does not return it

## Study focus
- Reading simple input
- Displaying program output
- Converting input to the needed type
