# Modules

## Core idea
A module is a Python file that groups related code so it can be imported and reused.

## What to check
- `import module_name`
- `from module import name`
- Standard library examples

## Common confusion
- A file can be both a script and a module
- Importing a module makes its names available based on the import style

## Study focus
- Basic imports
- Standard library awareness
- Organizing code across files
