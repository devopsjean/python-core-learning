# Errors and Exceptions

## Core idea
Exceptions handle runtime problems without crashing the whole program immediately.

## What to check
- `try`
- `except`
- `else`
- `finally`

## Common confusion
- Syntax errors happen before the program runs
- Exceptions happen while the program runs

## Study focus
- Catching basic exceptions
- Reading exception messages
- Protecting risky operations
