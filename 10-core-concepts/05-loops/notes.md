# Loops

## Core idea
Loops repeat a block of code until a condition changes or a sequence ends.

## What to check
- `for` loops with `range()`
- `while` loops with a stopping condition
- Loop control with `break` and `continue`

## Common confusion
- A `while` loop can run forever if the condition never changes
- `range(5)` starts at `0`

## Study focus
- Counting loops
- Iteration over sequences
- Basic loop control

## Next experiment
- Change the `range()` arguments
- Add a `break` when a target value appears
