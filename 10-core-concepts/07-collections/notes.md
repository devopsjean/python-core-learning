# Collections

## Core idea
Collections store multiple values in one object.

## What to check
- Lists for ordered mutable data
- Tuples for ordered immutable data
- Dictionaries for key-value pairs
- Sets for unique values

## Common confusion
- Lists use indexes
- Dictionaries use keys
- Sets remove duplicates automatically

## Study focus
- Sequence basics
- Dictionary access
- Membership tests
